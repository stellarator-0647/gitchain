# 2026-10-17 优化记录

## 本次范围

用户要求审视优化、修改、为 Claude 保留文档，并制作客户端。基于现有 仓库根目录 代码修改；没有覆盖历史开发或更改 origin，没有提交、推送、重置链。

## 修改项（原行为 → 新行为 → 原因）

1. `internal/verify/verify.go` 与 `verifier/src/verify.ts`：仅检查 validUntil → 首次包含的检查点时间必须位于 [validFrom, validUntil]。避免尚未生效的授权提前获得有效证据。消息自报 ts 仍不作为可信时间。时间无效事件继续包含在树中，不阻止后续锚定。兼容字段 delegationExpired 暂时也表示“早于开始时间”，后续若改名必须版本化。
2. `internal/node/delegation.go`：安装/使用授权增加当前时间下界检查；未来生效授权不能被节点提前安装。
3. `web/src/delegate.ts`：缓存键绑定 chainId、registry、room、wallet；内存回退也核对身份与部署。旧格式缓存不再复用。临时私钥仍在 sessionStorage，XSS 风险和没有链上吊销的限制仍存在。
4. `web/src/delegation-policy.ts`：在钱包签名前核对 Domain、权限、请求时长，以及 JSON delegation 与 typedData 两种表达的完整 EIP-712 摘要。不再只检查三个人类可读字段。
5. `web/src/api.ts`：请求增加 30 秒超时，避免界面无限等待。超时不代表提交一定失败，不自动重发交易；应先核对历史/链上结果。
6. `web/src/App.tsx`：停止使用按钮不再用“撤销”误导为全局吊销；添加桌面钱包入口和能力说明。
7. `cmd/gitchain/main.go`：默认 Origin 白名单增加 http://127.0.0.1:5174，供独立打包界面连接。原节点需重新编译/重启才生效；不得重置链。
8. `desktop/`：Electron 桌面壳、自带静态资源、固定 loopback HTTP 服务、浏览器钱包入口、打包脚本、服务边界测试、截图冒烟模式。没有私钥内置，没有装 MetaMask，没有给渲染进程 Node 权限。
9. 测试：新增浏览器授权篡改/权限/时长/部署测试；修改节点模拟区块时间，使正常授权测试不再把 2026 年授权锚定到 2023 年的区块。静态服务测试覆盖 Host、路径、方法、CSP。

## 不夸大优化范围

本次未实现多方锚定者、全局授权吊销、生产密钥托管、端到端加密、合同分支、完整独立 P2P。未对所有旧逻辑完成安全审计。Electron 内不声称支持 Chrome MetaMask；钱包路径在系统浏览器中使用。
